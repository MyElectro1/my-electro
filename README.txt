MY ELECTRO

Файлы приложения:
- index.html — приложение
- manifest.json — установка как мобильного приложения
- sw.js — офлайн-кэш
- icon-192.png / icon-512.png — иконка

Для GitHub Pages загрузите ВСЕ эти файлы в корень репозитория.
После публикации откройте адрес сайта на телефоне и выберите в браузере «Добавить на главный экран» / «Установить приложение».
